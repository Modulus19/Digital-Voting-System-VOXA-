# Poll & Voting App

## Requirements

- Node.js
- npm
- MongoDB
- Git

## Installation

### 1. Clone the repository

git clone <repository-url>

### 2. Backend

cd backend
npm install

Create a .env file using .env.example.

Start development server:

npm run dev

### 3. Frontend

cd frontend
npm install

Create a .env file using .env.example.

Start development server:

npm run dev
